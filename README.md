# سایت نمونه‌کار معماری و طراحی داخلی (Cloudflare Worker + D1 + Workers KV)

یک وب‌سایت مدرن با طراحی تحریریه (Editorial Obsidian)، تایپوگرافی بهینه فارسی (Vazirmatn)، هیرو با آواتار بزرگ و ۴ حباب ابری شناور همراه با کانکتور تفکر، پنل مدیریت پروژه‌ها، سفارش‌ها، تنظیمات هویت سایت و مدیریت کامل تصاویر با استفاده از Workers KV و دیتابیس لبه‌ای D1 (پلن ۱۰۰٪ رایگان کلادفلر بدون نیاز به کارت اعتباری یا R2).

---

## قابلیت‌های پیاده‌سازی شده

### ۱. هیرو و طراحی بصری (Hero & Visual Identity)
- **بدون کادر مستطیلی پس‌زمینه:** آواتار و حباب‌ها مستقیماً روی پس‌زمینه اصلی صفحه قرار دارند.
- **آواتار بزرگ‌تر و شاخص:** قطر ۱۷۰ تا ۲۰۵ پیکسل در موبایل و ۲۶۰ تا ۳۰۰ پیکسل در دسکتاپ، همراه با حلقه طلایی نازک (`--accent`) و افکت درخشش تنفسی (Breathing Glow).
- **۴ حباب ابری با کانتور واقعی:** شکل ابر ارگانیک با شیشه‌گری و افکت بلور، همراه با دنباله اتصالی سه‌نقطه‌ای (Thought-bubble connector) متصل به آواتار.
- **متن‌های ۴ حباب ابری:** کاملاً داینامیک و قابل ویرایش در پنل:
  1. `محمد فهیمی`
  2. `طراح داخلی`
  3. `نقشه‌کش`
  4. `از ایده تا اجرا`
- **انیمیشن و دسترس‌پذیری:** انیمیشن ورود نرم، حرکت شناور مستقل برای هر حباب و آواتار، توقف خودکار انیمیشن هنگام خروج هیرو از ویوپورت، و احترام کامل به `prefers-reduced-motion`.
- **اولویت پروژه‌ها:** چیدمان فشرده که باعث می‌شود بخش پروژه‌ها بلافاصله پس از هیرو در بالای صفحه موبایل (Above the Fold) نمایان باشد.

### ۲. مدیریت همه‌جانبه تصاویر در پنل مدیریت (Admin Image Management)
- **کامپوننت انتخابگر یکپارچه (`imagePicker`):** رابط کاربری مشترک در تمام تب‌ها برای بارگذاری مستقیم فایل WebP (با Drag & Drop) یا انتخاب از تصاویر موجود در کتابخانه.
- **تب سفارش‌ها (Orders):** مشاهده سفارشات، فیلتر وضعیت، جستجو، تغییر وضعیت، ثبت یادداشت داخلی و خروجی CSV.
- **تب پروژه‌ها (Projects):** ایجاد، ویرایش، حذف، مرتب‌سازی ترتیبی پروژه‌ها، افزودن چندین تصویر به گالری، جابجایی چپ/راست تصاویر با دکمه‌های لمسی (◄ ►)، جایگزینی سریع هر تصویر (🔄) و انتخاب تصویر کاور.
- **تب پروفایل (Profile):** تغییر/حذف تصویر آواتار، نام، عناوین شغلی، متن هر ۴ حباب ابری و متن کوتاه درباره استودیو.
- **تب تنظیمات سایت (Site Settings):** تغییر لوگوی اسپلش، تصویر پس‌زمینه اسپلش، نام استودیو و شعار.
- **تب کتابخانه رسانه (Media Library - Workers KV):**
  - مشاهده تمامی تصاویر بارگذاری‌شده با پیش‌نمایش، حجم، تاریخ و نام فایل.
  - تشخیص هوشمند محل استفاده تصویر (در کدام پروژه، آواتار یا اسپلش).
  - محافظت در برابر حذف تصاویری که در حال حاضر در سایت در حال استفاده هستند.
  - کپی مستقیم آدرس فایل در کلیپ‌بورد.

### ۳. ذخیره‌سازی ابری در Workers KV و کش لبه‌ای
- **پلن کاملاً رایگان (بدون نیاز به کارت اعتباری):** ذخیره‌سازی تصاویر در Workers KV با کلیدهای محتوا‌محور (`img:<hash>.webp`).
- **کش لبه‌ای (Cache API):** کش پاسخ‌های `/api/media/*` در `caches.default` با هدرهای `immutable, max-age=31536000` جهت حفظ محدودیت خواندن KV (۱۰۰ هزار درخواست در روز).
- **اعتبارسنجی WebP:** پذیرش انحصاری فرمت WebP با بررسی بایت‌های جادویی `RIFF....WEBP` در سرور و سقف حجم ۳ مگابایت.

## چک‌لیست تصاویر قابل ویرایش در سایت (Image Audit)

تمامی تصاویر زیر بدون نیاز به هیچ‌گونه تغییر کد یا کامیت در گیت، مستقیماً از پنل مدیریت قابل ویرایش، جایگزینی یا حذف هستند:
1. **آواتار پروفایل:** تب پروفایل (`site.profile.image`)
2. **تصویر شاخص / کاور پروژه‌ها:** تب پروژه‌ها (`project.cover`)
3. **تصاویر گالری پروژه‌ها:** تب پروژه‌ها (`project.images[]`)
4. **تصویر هیروی صفحه پروژه:** از اولین تصویر گالری پروژه لود می‌شود
5. **تصویر پیش‌نمایش پروژه بعدی:** تصویر کاور پروژه بعدی به صورت خودکار استفاده می‌شود.
6. **تصاویر لایت‌باکس بزرگنمایی:** از گالری پروژه لود می‌شود
7. **لوگوی اسپلش اول سایت:** تب تنظیمات سایت (`site.splash.logo`)
8. **تصویر پس‌زمینه اسپلش:** تب تنظیمات سایت (`site.splash.image`)

## راه‌اندازی و دیپلوی در Cloudflare

### ۱. ساخت یا تنظیم نیم‌اسپیس Workers KV
در فایل [wrangler.jsonc](wrangler.jsonc) شناسه نیم‌اسپیس `MEDIA` از پیش تنظیم شده است. در صورت راه‌اندازی روی یک اکانت تازه کلادفلر، دستور زیر را اجرا کنید:
```bash
npx wrangler kv namespace create MEDIA
```
سپس شناسه جدید نمایش‌داده‌شده را در `wrangler.jsonc` در بخش `kv_namespaces` جایگزین کنید.

### ۲. ساخت و اجرای دیتابیس D1
اگر دیتابیس `portfolio-orders` را نساخته‌اید:
```bash
npx wrangler d1 create portfolio-orders
```
سپس مایگریشن‌های دیتابیس را با دستور رسمی مایگریشن کلادفلر اعمال کنید:
```bash
npx wrangler d1 migrations apply portfolio-orders --remote
```

> **نکته در مورد پروژه‌های نمونه (Seed)**:
> روی نصب تازه، جدول پروژه‌ها خالی است. در صورت تمایل به بارگذاری ۴ پروژه نمونه، دستور زیر را اجرا کنید:
> ```bash
> npx wrangler d1 execute portfolio-orders --remote --file=seed/demo_projects.sql
> ```

### ۳. تنظیم رمز ورود به پنل مدیریت (`/admin/`)
```bash
npx wrangler secret put ADMIN_PASSWORD
```
*(پس از اینتر، رمز عبور دلخواه خود را وارد نمایید)*

> 🔒 **مکانیزم احراز هویت پنل مدیریت:**
> ورود به پنل از طریق ارسال رمز عبور به اندپوینت `POST /api/admin/login` انجام می‌شود. در صورت صحت رمز، سرور یک توکن امضاشده با HMAC-SHA256 (با کلید `ADMIN_PASSWORD` و مهلت ۸ ساعته) صادر کرده و آن را در قالب کوکی امن (`HttpOnly; Secure; SameSite=Strict; Path=/api/admin`) برمی‌گرداند. رمز عبور در هیچ‌یک از فضاهای ذخیره‌سازی سمت کلاینت (مانند `sessionStorage`) نگهداری نمی‌شود و خروج با ارسال درخواست به `POST /api/admin/logout` کوکی را پاک می‌کند. در تلاش‌های ناموفق ورود نیز محدودیت نرخ (Rate-limiting) با ثبت در دیتابیس D1 اعمال می‌گردد.

### ۴. انتشار نهایی روی کلادفلر (Deploy)
```bash
npx wrangler deploy
```

## تست محلی روی سیستم (اختیاری)

> ⚠️ **هشدار امنیتی:** فایل `.dev.vars.example` (با مقدار `ADMIN_PASSWORD=test`) صرفاً برای توسعه و تست لوکال است. در محیط پروداکشن حتماً باید از دستور `npx wrangler secret put ADMIN_PASSWORD` همراه با یک رمز عبور قوی و امن استفاده شود. هرگز مقادیر محرمانه یا فایل `.dev.vars` را به گیت کامیت نکنید.

۱. ایجاد فایل `.dev.vars` در ریشه پروژه بر اساس نمونه `.dev.vars.example`:
```env
ADMIN_PASSWORD=test
```

۲. اجرای مایگریشن‌های محلی D1:
```bash
npx wrangler d1 migrations apply portfolio-orders --local
```
*(اختیاری: جهت بارگذاری پروژه‌های نمونه در محیط لوکال: `npx wrangler d1 execute portfolio-orders --local --file=seed/demo_projects.sql`)*

۳. اجرای لوکال با شبیه‌ساز KV و D1:
```bash
npx wrangler dev
```
*(در محیط لوکال، دستور `wrangler dev` نیم‌اسپیس KV را به صورت خودکار شبیه‌سازی می‌کند).*
